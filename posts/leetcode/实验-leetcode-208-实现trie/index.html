核心假设 (Hypothesis)

一个 Trie 树节点通常要存如下信息：

  • 子节点引用，由于默认只有 26 个小写字母，因此，可以用 children[26] 表示
  • 结束标记 isEnd，用来表示这是一个完整的单词

插入操作：

  • 子节点不存在，则创建出来
  • 走完完整单词后，设置 isEnd

查询操作：

  • 对应字符不存在，返回 false
  • 走完整个单词，需要判断 isEnd 是否为 true
