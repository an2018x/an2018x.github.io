  1. 整体流程
    • 前端创建 EventSource，浏览器发起一个 HTTP 请求到指定 URL
    const source = new EventSource("/events");

source.onmessage = (event) => {
    console.log(event.data);
};

source.onerror = (err) => {
    console.error("SSE error", err);
};
    • 浏览器会发起一个 HTTP 请求，带上 Accept: text/event-stream
    • 服务器返回特定响应头 Content-Type: text/event-stream
    • 服务端持续写入事件流，每个事件之间靠空行分隔，浏览器会变读边解析，不需要等待整个响应结束
    data: hello

data: world

event: notice
data: task finished
    • 浏览器按规则解析并派发事件
    • 短线自动重连，通过 Last-Event-ID 实现断点续传语义
