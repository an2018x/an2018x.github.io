重启人生

- 重启人生 - 重要 - 万事切不可急躁，三思而后行 - 时刻佩戴苹果手表，用番茄时钟记录消耗的时间 - 早上起来不要看手机，先看本篇文章 - 压力大时，需要运动，公司脑子一片空白，跑步机跑步 - 不需要焦虑，没有天塌下来的事 - 定时打扫卫生，东西用完一定要归位 - 行动比犹豫更重要 - 每件事情都要认真对待 - 生活 - 早晨 - 早起喝一杯水，控制在 8:00 - 9:00 起床 - 早晨散步接触阳光，买早餐或者自己做早餐 - 吹头发 - 整理仪表 - 用纸随便写一些东西，一页就好 - 中午 - 中午午睡不要在床上睡，很容易睡过头 - 中午时间容易浪费，建议早睡，睡后散步 - 将焦虑写在纸上，不要带到睡眠 - 将明天的 3 条待办写在纸上 - 下午 - 下午是工作的黄金时间，休息的垃圾时间，不要浪费，重要的工作要在下午解决 - 睡眠 - 睡前打扫卫生 - 睡前喝蛋白粉 + 肌酸 - 睡前拉伸肌肉 - 中午睡眠 20 分钟 - 洗面奶清洁 - 贴口呼吸贴 - 卫生 - 东西放在固定的地方 - 空调遥控器，床头柜 - 手机，床头柜 - 耳机，床头柜 - 梳子、剃须刀，梳妆台 - 东西拿完后放在固定的地方 - 小便要抖干净 - 经常刷鞋 - 垃圾及时丢到垃圾桶 - 鞋子放在鞋架，第二天穿的鞋及时晾晒 - 床上不要放不必要的东西 - 身体状态 - 手脚冰冷要及时注意保暖 - 运动 - 保持散步，每天关闭活动圆环 - 经常游泳 - 尝试纠正脊椎侧弯，每天吊一会单杠 - 养成健身房健身的习惯 - 心理 - 任何时候，只要身体没有疲劳，就应该立即行动 - 不要焦虑内耗 - 焦虑的时候，戴上耳机去跑步 - 经常和 chatgpt 对话 - 社交 - 积极了解和整理当下热点话题 - 把嗯、哦换成清晰短句 - 1 - 3s 的眼神接触 + 微表情 - 需求直给，减少内心纠结 - 适当接话，不要逃避和宕机 - 避免成为透明人，也不抢戏 - 按照练习而不是表演的心态和别人交流，每次交流都是完成一个小目标 - 将重心放在自己而不是别人的感受上面 - 聊天万能公式 = 观察 + 具体提问/小感叹 + (可选)递话茬 - 观察：正在发生的事情，例如排队、电梯 - 具体提问：基于观察给出具体提问，不要大而空泛 - 放弃完美接话 - 表达共鸣 + 一点细节 - 不硬接不懂的话题 - 不过度解读 - 不要使用哦、嗯、啊、好的，试着带点内容 - 狭小空间 - 眼神接触 + 点头/微笑 + 简单问候 + 不看手机 + 不硬聊 - 不想参与对话 - 直接 + 礼貌 + 简短拒绝 + 不编复杂借口 - 线上沟通 - 收到消息，不秒回，给自己一个缓冲 - 回复带表单和语气词，例如 ～、哈、谢谢 - 收到了 @ ，不装死，简单回复“收到，在处理了“。 - 休息 - 听一听播客 - 休息时不要玩手机，统计一天的手机使用时长 - 除了睡觉时间不要躺在床上 - 像安排会议一样安排娱乐，5 分钟，不受外界干扰 - 工作 - 建立 SOP - 目标是什么，知道具体为什么做 - 要有核心步骤和运行标准 - 包含注意事项 - 跨部门合作 - 目标：解决跨部门对接不敢问、问不清、跟进无上下文的痛点 - 核心步骤 - 对接前准备 - 明确三个核心信息：需求信息、截止时间、交付标准 - 找好对接人：直属领导、项目经理、部门同事 - 对接时 - 问候+背景+需求+标准+时间 - 主动问反馈时间 - 沟通后 - 发文字确认：文字留痕 - 对接信息记录到任务协作记录表（对接人、需求、截止时间、反馈节点） - 跟进与闭环 - 到时间没反馈，主动询问 - 按照约定时间跟进进度，完成后发感谢消息，同时更新协作记录表为已完成 - 工作周报 SOP - 目标：避免周报写的像流水账、方案漏关键信息、重复修改，让成果输出有逻辑、符合要求，避免返工 - 核心步骤 - 写前收集：每周五上午 10 点 - 收集 3 类素材：本周完成的任务，任务对应的数据、遇到的问题 - 参考公司流程框架 - 撰写内容 - 本周工作成果：重要程度排序，不说做什么，要说做成了什么 - 数据汇总：清晰直观 - 问题与改进：不只说问题，要说问题 + 改进思路 - 下周计划：优先级排列 - 自查 - 数据是否准确 - 逻辑是否清晰 - 任务是否有漏 - 提交和反馈 - 邮件发直属领导 - 领导反馈，记录需要改进的点， - 进度和风险及时和领导同步 - 养成专注的习惯，尽量进入心流状态 - 拉齐会议前要有议程，会议结束后要有总结并同步到群内，会议前记得开启会议录制 - 不要直接答应别人的要求，学会拒绝 - 做事情前期给出明确的时间点 - 学会排期和估时 - 坐姿端正，不要翘二郎腿 - 学会拆解任务 - 使用番茄时钟，5 分钟进行时间审计，制定 SOP 的目标 - 营养 - 购买鱼油、复合维生素、锌补剂 - 记录 - 每日进行复盘，建一个文件夹，将每天做的事情记录下来 - 每天早晨进行记录想法 - 投资 - 定投纳指 + 标普 + 上证 + 沪深 - 学习 - 使用费曼学习法 - 使用思维导图 - 学习演讲能力 - 学习编写文档的能力 - 学习沟通能力 - 学习唱歌、简单舞蹈 - 学习聚会小游戏 - 决策 - 决策前要深思熟虑，重大决定不轻易下达 - 购物 - 极简主义，不买不需要的东西
