API 网关是提供给应用程序客户端的单点入口，通常位于客户端和一系列后端服务中间。

API 网关会提供一系列功能：

* 身份认证+安全策略
* 负载均衡
* 熔断保护
* 协议转换
* 服务发现
* 监控
* 日志
* 计费
* 缓存
