# 下载 Raycast

https://www.raycast.com/go

选择 download raycast for mac

# 替换 spotlight 聚焦搜索快捷键


1. 打开设置，搜索"键盘快捷键"并选中"键盘快捷键"选项

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825003744.png)

2. 选择聚焦，取消选中 『显式聚焦搜索』和 『显式访达搜索窗口』

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825003823.png)

3. 设置 RayCast 快捷键为 Command + Space

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825003943.png)

# 剪切板插件

1. 打开设置 -> Extensions -> ClipBoard History -> 设置快捷键 Commond + Shift + V

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825004054.png)

2. 按 Command + Shift + V 快捷键即可唤起剪切板

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825004855.png)

# Create QuickLink

1. 搜索 Create QuickLink

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825004511.png)

2. 点击，输入 Name + Link，完成后选择 Save Quicklink

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825004618.png)

3. 唤起 RayCast，搜索 bing (之前设置的 Name)，点击即可用浏览器打开链接

    ![](https://an-img.oss-cn-hangzhou.aliyuncs.com/2025%2F08%2F2520250825004745.png)
