| Go 命令   | 作用                    |
| ---       |----                     |
|  go build |  编译 go 文件            |
|  go run   |  编译并执行 go 文件       |
|  go fmt   |  格式化当前目录下的所有代码 |
|  go install   |  编译和安装包 |
| go get | 下载源码或者其他人的包 |
| go test | 运行单元测试 |
