# Back-of-the-envelope

系统粗估（信封背面粗估）通常用来快速确认系统设计是否合理。

系统粗估不需要太精准。

# 扩容

如果估算出我们的 Web 服务需要每秒承载 1M 的请求，每个 web 服务器只能承载 10k/s 的请求。

因此，我们需要一个包含 100 台服务器的 Web 服务器集群，同时需要一个负载均衡服务器在他们前面。
