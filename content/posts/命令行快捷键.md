# 操作列表

| 操作| 快捷键 |
|  ----  | --- |
| 光标移动到开头 | Control - A|
| 光标移动到结尾 | Control - E|
| 光标前移一个单词 | Option - <- |
| 光标后移一个单词 | Option - -> |
| 打开 iterm 配置 | Command - , |
| 删除行 | Control - U |
| 删除到行的结尾 | Control - K |
| 向后删除到行的开头 | Control - W |
| 新建窗口 | Control - K |
