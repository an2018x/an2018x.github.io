类别规则示例
标准 JSON 类型object · array · string · number · true · false · null{"x": 1, "y": [true, null]}
不支持undefined · NaN · Infinity · 注释 · 末尾逗号 · 单引号 · 函数这些是 JS 字面量,非 JSON
字符串转义\" \\ \/ \b \f \n \r \t \uXXXX"hello \"world\"\n"
数字不允许前导 +、不允许 .5(必须 0.5)、不允许 1.(必须 1.0)-3.14e10
键必须是双引号包裹的字符串"k": 1 ✓    k: 1 ✗
JSON Pointer路径用 / 分隔,数组用下标,空段表根/data/users/0/name
大小限制JS 数字精度 53 位,大整数会丢精度9007199254740993 → 9007199254740992
